## 蓝灯与连接恢复记录

操作者反馈：实际采集期间，多数时候蓝灯常亮，控制台同时显示“连接恢复中”。本批软件日志记录了 136 次重建触发，其中包括数据中断和初始化失败：

| 日志原因 | 次数 |
| --- | ---: |
| 连续 3 秒无新 EEG 样本 | 75 |
| 样本包序号不连续 | 21 |
| 初始化写入失败 | 26 |
| 建连超过截止时间 | 12 |
| 通道配置命令失败 | 1 |
| 启动数据流失败 | 1 |

记录器累计登记 79 次已有数据的连接中断、62 次恢复收数，另有 33 次清理超时后结束采集子进程。主动强制重连次数为 0。恢复状态可计算的累计下界为 1235.185 秒，即 20 分 35.185 秒。

恢复时长从首个故障事件算到恢复收数或停止；中间多次连接尝试合并计算。S01 的 15:07 旧记录缺少最后停止事件和整场时长，因此累计值采用下界。等待稳定信号包含积累窗口的时间，与恢复状态存在重叠，两项分别保留。

灯态来自操作者观察；日志描述上位机是否收到新样本。当前文件没有原始 TCP 接收字节和灯态时间线，设备发送、无线传输与底层接收三个环节仍需通过通信记录定位。下一步对照采用厂商 GUI 与当前采集器的同条件持续采集，并记录原始字节到达时间与包序号。
