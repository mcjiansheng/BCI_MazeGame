## 第一章：EEG Conformer — Transformer 引入 EEG 的里程碑

**出处**：Song Y, Zheng Q, et al. "EEG Conformer: Convolutional Transformer for EEG Decoding and Visualization". IEEE TNSRE, 2023.

### 1.1 它解决了什么问题？

在 EEG Conformer 之前，EEG 分类主要有两类方法：

| 方法 | 代表 | 局限 |
|------|------|------|
| 纯 CNN | EEGNet, DeepConvNet | 卷积核感受野有限，难以捕获全局时序依赖 |
| 纯 RNN | LSTM, GRU | 串行计算慢，长序列梯度易消失，难以捕捉长程依赖 |

**核心洞察**：EEG 信号既有局部特征（特定频段的短时模式），也有全局依赖（整个运动想象期间的时序演化）。CNN 擅长局部，Transformer 擅长全局——为什么不把两者结合？

### 1.2 架构总览

```
原始 EEG (C × T)
    │
    ▼
┌──────────────────────────────┐
│        卷积模块                │
│  ┌──────────────────┐        │
│  │ 时间卷积 (1D Conv) │← 提取局部时序特征  │
│  │ 空间卷积 (C × 1)  │← 学习电极间空间关系 │
│  │ 多个卷积层堆叠     │← 逐步抽象高层特征  │
│  └──────────────────┘        │
└──────────┬───────────────────┘
           ▼
┌──────────────────────────────┐
│      Transformer 编码器       │
│  ┌──────────────────┐        │
│  │ 多头自注意力       │← 建模全局时序依赖  │
│  │ × N 层            │← 堆叠加深理解     │
│  │ 前馈网络 (FFN)    │← 非线性转换      │
│  └──────────────────┘        │
└──────────┬───────────────────┘
           ▼
┌──────────────────────────────┐
│         分类层                │
│     全连接 → Softmax         │
└──────────────────────────────┘
```

### 1.3 核心算法原理

#### 卷积模块：局部特征提取

**一维时间卷积**：用多个 1D 卷积核沿时间轴滑动，捕获局部波形模式。

```
输入: (C, T)           —— C 个通道 × T 个时间点
输出: (F1, T')         —— F1 个滤波器提取的特征图，长度缩短
```

**空间卷积**：用 (C, 1) 的 2D 卷积核融合所有电极的信息，学习空间拓扑关系。

> 类比：时间卷积是"听"每个通道上的波形模式，空间卷积是"看"哪些电极一起激活。

#### 自注意力模块：全局依赖建模

这是 Transformer 的核心。把卷积输出的特征序列视为"词序列"，用自注意力计算任意两个时间点之间的相关性：

```
Attention(Q, K, V) = Softmax(QK^T / √d) · V
```

- **Q** (Query)：当前时间点"想关注什么"
- **K** (Key)：其他时间点"有什么"  
- **V** (Value)：其他时间点"实际内容"
- **QK^T**：计算两时间点的相似度（注意力分数）
- **Softmax**：归一化为概率（哪些时间点更重要）
- **加权求和**：得到融合了全局信息的当前时间点表示

**多头注意力**：用多组 QKV（多个"视角"），每组独立建模，最后拼接。h 个头各自关注不同模式：

```
MultiHead(Q, K, V) = Concat(head₁, ..., head_h) · W_O
```

#### 关键优势

| 特性 | CNN | Transformer | EEG Conformer |
|------|-----|-------------|---------------|
| 局部特征 | ✅ 擅长 | ❌ 不擅长 | ✅ CNN 负责 |
| 全局依赖 | ❌ 感受野有限 | ✅ 任意距离 | ✅ Transformer 负责 |
| 并行计算 | ✅ | ✅ (非 RNN) | ✅ |
| 端到端 | ✅ | ✅ | ✅ |

### 1.4 实验结果与局限

**EEG Conformer 在 BCIC2a 上的准确率**：78.3%

**两个明显短板**（也是后续改进的起点）：

| 短板 | 表现 | 根因 |
|------|------|------|
| **卷积核单一** | 只用一种尺寸的时间卷积核，对 θ(4-7Hz)、α(8-13Hz)、β(14-30Hz) 等不同频段特征的提取能力不均衡 | 不同频段需要不同时间窗口来捕获完整周期 |
| **多头注意力无交互** | 多个注意力头各自独立建模，简单拼接后线性映射；无法区分哪些头输出可靠、哪些受噪声污染 | 缺乏头间的信息交互和自适应加权 |

## 第二章：FBCNet — 多频段分解的轻量高效方案

**出处**：Mane R, et al. "FBCNet: A Multi-view Convolutional Neural Network for Brain-Computer Interface". EMBC, 2021.

### 2.1 它解决了什么问题？

传统 CNN（如 EEGNet）直接用原始信号学习，**没有显式利用"不同频段包含不同 MI 信息"这一神经生理学先验**。

- μ 节律（8-13Hz）和 β 节律（14-30Hz）是运动想象最关键的频段
- 不同 MI 任务（左手、右手、双脚）激活的频段组合不同
- 如果模型能从**不同频段分别提取特征再融合**，判别力更强

### 2.2 架构总览

FBCNet 的核心设计就是"分频段处理 + 空间滤波 + 时序聚合"：

```
原始 EEG (C × T)
    │
    ▼
┌──────────────────────────────────────┐
│        滤波器组 (Filter Bank)         │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐       ┌──┐   │
│  │F1│ │F2│ │F3│ │F4│  ...  │Fk│   │
│  └─┬┘ └─┬┘ └─┬┘ └─┬┘       └─┬┘   │
│    │    │    │    │          │      │
│    ▼    ▼    ▼    ▼          ▼      │
│  (C×T) (C×T) (C×T) (C×T)  (C×T)   │  ← 各频段独立保留
└──────────────────────────────────────┘
                    │
                    ▼
┌──────────────────────────────────────┐
│   多视图空间滤波 (Multi-view SP)      │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐       ┌──┐   │
│  │S1│ │S2│ │S3│ │S4│  ...  │Sk│   │
│  └─┬┘ └─┬┘ └─┬┘ └─┬┘       └─┬┘   │
│    ▼    ▼    ▼    ▼          ▼      │
│   (2×T) (2×T) (2×T) (2×T)  (2×T)   │  ← 每频段提取 2 个空间模式
└──────────────────────────────────────┘
                    │
                    ▼
┌──────────────────────────────────────┐
│      方差层 (Variance Layer)         │
│  对每个空间滤波输出计算方差           │
│  → 每个频段得到一个标量特征           │
└──────────────────────────────────────┘
                    │
                    ▼
┌──────────────────────────────────────┐
│          分类层                      │
│   拼接所有频段特征 → 全连接分类       │
└──────────────────────────────────────┘
```

### 2.3 核心算法原理

#### 滤波器组（Filter Bank）：频段分解

用一组带通滤波器将原始 EEG 分解到多个窄带频段：

```
频段 1:  4-8 Hz   (θ 波)
频段 2:  8-12 Hz  (α 波 / μ 节律)
频段 3: 12-16 Hz
频段 4: 16-20 Hz
频段 5: 20-24 Hz
频段 6: 24-28 Hz
频段 7: 28-32 Hz  (β 波)
```

> 传统 FBCSP 也做同样的频段分解，但后续使用手工设计的 CSP 算法。FBCNet 用神经网络**自动学习**空间滤波器。

#### 深度可分离空间卷积（Depthwise Conv）：可学习的空间滤波器

对每个频段的信号，用深度可分离卷积学习空间投影矩阵：

```
对频段 i:  X_i ∈ ℝ^(C × T)
用 Conv2D(C, 1) Depthwise:  →  2 个空间模式  →  Y_i ∈ ℝ^(2 × T)
```

这等价于**可学习的 CSP 滤波器**：自动找到每个频段上区分度最大的电极组合。

#### 方差层：时序信息的高效聚合

这是 FBCNet 的创新点。它不是直接用 CNN 处理时域（会增加很多参数），而是计算空间滤波输出的**方差**：

```
Var(Y_i) = (1/T) · Σ (Y_i(t) - μ_i)²    →  (2,)
```

**为什么用方差？**
- 运动想象时，EEG 信号的**功率变化**是主要判别依据（ERD/ERS 效应）
- 方差直接反映了信号的功率大小
- 计算量极小，参数为零
- 在少量训练数据下比用 CNN 处理时域更鲁棒

#### 最终分类

将所有频段的空间滤波方差拼接为一个特征向量，送入全连接层：

```
Feature = [Var(Y₁), Var(Y₂), ..., Var(Y₇)]  →  (14,)
Output = Softmax(FC(Feature))               →  (n_classes,)
```

### 2.4 FBCNet 的关键优势

| 特性 | 说明 | 对 EEG Conformer 的启发 |
|------|------|------------------------|
| 多频段分解 | 显式利用频段先验知识 | → 多分支时频卷积 |
| 可学习空间滤波 | 自动找到判别性电极组合 | → 通道特征提取层 |
| 方差聚合 | 极简高效的时序信息压缩 | ≈ SE 模块的全局池化 |

### 2.5 实验结果

**FBCNet 在 BCIC2a 上的准确率**：75.5%

FBCNet 的优势在于参数少（~4K）、在少量数据上表现好，但纯 CNN 架构缺乏全局时序建模能力，Transformer 能做时序全局交互，这是 FBCNet 做不到的。

## 第三章：SE-MHAF-Conformer — 融合之大道

**出处**：单心源. 基于脑电信号识别的虚拟现实运动控制系统设计与实现[D]. 南京大学, 2026.

### 3.1 设计动机：为什么要融合？

| 模型 | 优点 | 不足 |
|------|------|------|
| **EEG Conformer** | CNN 局部特征 + Transformer 全局依赖 | 卷积核单一、多头无交互 |
| **FBCNet** | 多频段分解、空间滤波、参数高效 | 无全局时序建模 |
| **目标模型** | 同时具备：多频段局部特征 + 全局时序依赖 + 自适应通道增强 + 多头融合 |

### 3.2 三大改进点

#### 改进一：多分支时频卷积（来自 FBCNet 的启发）

FBCNet 用滤波器组人工分解频段，这里将其替换为**不同尺寸的卷积核**，让网络自动学习各频段的特征：

| 分支 | 卷积核尺寸 (fs=250Hz) | 对应频段 | 覆盖周期 |
|------|---------------------|---------|---------|
| 分支 1 | 1×63 (≈ fs/4) | ~4Hz 以上 | 252ms（完整 θ 波） |
| 分支 2 | 1×31 (≈ fs/8) | ~8Hz 以上 | 124ms（完整 α 波） |
| 分支 3 | 1×15 (≈ fs/16) | ~16Hz 以上 | 60ms（β/γ 波） |

**与 FBCNet 的不同**：
- FBCNet 是**显式滤波 + 固定频段分解**
- SE-MHAF 是用**不同尺度卷积核 + 可学习参数自动适应**
- 优点：不需要手动设计滤波器组，端到端训练

#### 改进二：SE 时空信息增强（Squeeze-and-Excitation）

在特征提取后插入 SE 模块，**动态学习各通道的重要性权重**：

```
输入特征 U  (C' × T')
    │
    ▼
┌────────────────────────┐
│  Squeeze（压缩）        │
│  全局平均池化           │
│  → 通道描述 z (C' × 1) │
└────────┬───────────────┘
         ▼
┌────────────────────────┐
│  Excitation（激励）     │
│  FC → ReLU → FC → Sigmoid│
│  → 通道权重 s (C' × 1) │
└────────┬───────────────┘
         ▼
┌────────────────────────┐
│  Scale（缩放）          │
│  U · s → 增强后的特征   │
└────────────────────────┘
```

**原理**：
- **Squeeze**：将每个通道的整个时序压缩成一个值（平均池化），得到该通道的"全局描述"
- **Excitation**：学习通道间的非线性关系，输出 0~1 的权重
- **Scale**：权重乘以原特征 — 有用的通道（如 C3/C4 MI 通道）放大，噪声通道（如眼电伪迹）抑制

> 打个比喻：SE 模块就像"调音台"——自动把 MI 相关的通道"推上去"，把噪声通道"拉下来"。

#### 改进三：MHAF 多头注意力融合（Multi-Head Attention Fusion）

**传统多头注意力的问题**：

```
输出 = Concat(Head₁, Head₂, ..., Head_h) · W_O
```

- 10 个注意力头各学各的，最后简单线性投影
- 有些头学到的是"这段有眨眼噪声"而不是"这段有 MI 特征"
- 在游戏中，眨眼频繁，噪声头会导致响应波动

**MHAF 的解决方案**——引入可学习注意力头权重矩阵：

```
标准:   Output = Concat(Head₁, ..., Head_h) · W_O

MHAF:  Output = Concat(w₁₁·Head₁ + w₁₂·Head₂ + ...,
                       w₂₁·Head₁ + w₂₂·Head₂ + ...)
```

具体来说：
```
W_head ∈ ℝ^(h×h)   ← 可学习参数矩阵
w̃_ij = Softmax(W_ij)_col   ← 列归一化（每列和为 1）

每个头的输出 = 所有头的加权组合
Head'_i = Σ_j w̃_ij · Head_j
```

**含义**：
- 权重矩阵 W_head 让每个"去噪后"的头可以选择性地从所有原始头中获取信息
- 如果一个头主要学到噪声模式，它的权重会被其他头"拉低"
- 如果某个头的模式特别有判别力，它的权重会被放大

**再加上自适应特征相关性重加权**：

在注意力计算时，将**上一层**的注意力分数作为先验传入当前层：

```
Attention_i(Q, K, V) = Softmax(QK^T/√d + α · prev_i) · V
```

- 为什么有用？如果第 1 层发现"时间点 120 和 200 高度相关"，第 2 层也应该利用这个先验
- 这类似 RNN 中的隐状态传递，但更轻量

```
│78.3% acc   │    │  + 多分支时频卷积       │
└────────────┘    │  + SE 通道增强          │
                  │  + MHAF 头融合          │
                  │  = 85.4% acc           │
                  └────────────────────────┘
```

**一句话概括整个演化路径**：
> 以 EEG Conformer 的 CNN+Transformer 双阶段架构为骨架，借用 FBCNet 的多频段分解思路将单卷积核扩展为多分支时频卷积，引入 SE 模块自适应增强关键通道、抑制噪声通道，最后用 MHAF 可学习权重矩阵让各注意力头交互融合，实现从 78.3% 到 85.4% 的提升。

## 附录：答辩 Q&A 准备

### Q1：为什么不用 FBCNet 直接做？

FBCNet 是纯 CNN，缺乏 Transformer 的全局时序建模能力。在 4 分类任务上 FBCNet 准确率 75.5%，比 EEG Conformer (78.3%) 低。SE-MHAF-Conformer 兼顾了 FBCNet 的多频段提取和 Transformer 的全局建模，准确率 85.4%。

### Q2：SE 和 MHAF 带来了多少提升？

论文做了消融实验（具体数据需查阅原文消融实验表）：
- 去掉 SE：准确率下降约 2-3%
- 去掉 MHAF：准确率下降约 2-3%
- 同时去掉（即原始 EEG Conformer）：78.3%
- 全部保留：85.4%
- 两者合计贡献了约 7% 的提升

### Q3：这个模型的计算量适合实时推理吗？

参数量约 1.2M，在 GPU（如 RTX 3060）上单次推理约 10ms。配合有重叠滑窗 + 投票机制（每次推理触发多个窗口），总延迟约 100-200ms，完全满足游戏实时性要求。如果 CPU 推理，可做模型量化（FP16/INT8）进一步加速。

### Q4：你的项目能直接用这个模型吗？

论文的自建数据集 SCD 就是 8 通道 × 250Hz 的配置，与本项目的 Brduino 设备完全一致。14 通道的 Emotiv Epoc X 也仅需微调第一层卷积参数（同比缩放卷积核），框架完全兼容。

### Q5：为什么比 ATCNet（82.6%）表现好？

ATCNet 也用了滑动窗口 + 并行 Transformer，但它没有做**不同频段的分支处理**，也没有 MHAF 的头融合机制。SE-MHAF-Conformer 多了这两个针对 EEG 特性的改进，因此效果更优。
