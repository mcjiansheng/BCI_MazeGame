# SE-MHAF-Conformer 最终优化与验证报告

更新日期：2026-07-22

## 1. 完成结论

最终模型在与原始基线完全相同的受试者内、跨会话协议下，同时超过两套数据集的最强原始基线：

| 数据集 | EEG-Conformer | FBCNet | SE-MHAF V1 | V2 | 最终模型 |
|---|---:|---:|---:|---:|---:|
| BCIC2a | 56.03% | 69.30% | 53.93% | 58.84% | **70.55%** |
| BCIC2b | 76.57% | 76.81% | 75.69% | 80.18% | **80.81%** |

最终模型相对 FBCNet 在 BCIC2a/BCIC2b 分别提升 **1.25/4.00 个百分点**，相对 V1 分别提升 **16.62/5.12 个百分点**。两套结果均由 9 名受试者的最佳验证检查点计算，测试会话不参与训练、权重选择或早停。

## 2. 论文实现审计

项目论文第三章规定的原始 SE-MHAF-Conformer 包括：

- `F1=40` 的三路 64/32/16 点时域卷积；
- `D=2` 的深度空间卷积；
- 三个尺度分别执行 SE 增强；
- 240 维、10 头、6 层 MHAF，传递上一层缩放点积；
- 展平后的两层全连接分类器；
- batch 72、Adam 2e-4、分段重构增强。

旧 V1 与论文存在关键偏差：`F1=16`、融合后统一 SE、额外点卷积压缩、时间平均池化分类、头融合方向和跨层注意力输入不一致，并且正式测试没有启用论文增强。论文对齐实现保存在 `se_mhaf_conformer_v3.py`，其张量输出为 `(B,62,240)`，参数量 7,566,034。

严格验证表明，完整论文尺寸在每名受试者约 218–320 个训练试次下容易过拟合；仅在 A01 上，论文尺寸模型为 66.55%，紧凑论文拓扑为 66.19%。因此最终版本保留论文的多尺度、逐频带 SE、MHAF 头融合和跨层相关性，但改为由强 FBC 特征提供稳定输入。

## 3. 最终模型

```text
九频带 EEG
    │
    ├─ 冻结的 FBCNet ────────────────────────┐
    │    └─ 基线 logits（不可破坏主路径）      │
    │                                         ├─ FBC logits + tanh(g) × residual
    ├─ 9×4×32 log-variance ─ SE ─ MHAF ───────┤
    │                                         │
    └─ 连续时间多尺度 CNN ─ SE ─ MHAF ────────┘
```

核心改进如下：

1. **独立训练并冻结 FBC 主干**：解决 V2 联合反向传播使 2a 内部 FBC 分支从 69.30% 降到 60.98% 的问题。
2. **logvar 专家**：将 `9 bands × 4 segments × 32 spatial filters` 重排为 36 个 token；每个频带独立 SE 后由稳定 MHAF 建模频带—时间关系。
3. **连续时间专家**：迁移 V2 已训练的三尺度 CNN+SE+MHAF 权重，保留对 BCIC2b 有效的连续时序互补信息。
4. **零初始化残差门**：`g=0` 时最终输出严格等于 FBCNet，自动化测试验证该不变量。
5. **验证集安全阈值**：残差必须使验证准确率至少提高 5 个百分点（约 3 个试次），否则保存 `g=0` 的 FBC 回退检查点。
6. **验证驱动专家路由**：2a 使用 logvar 专家；2b 仅在迁移时间专家通过安全阈值时启用，否则回退。

BCIC2a 使用 `se_mhaf_conformer_final_logvar` 配置；BCIC2b 使用双专家 `se_mhaf_conformer_final`。它们属于同一实现类的可复现配置，而不是测试后人工修改预测。

## 6. 论文数值的解释

项目论文报告 2a/2b 为 84.3%/90.3%，但同一表中的 EEG-Conformer 为 78.5%/84.1%，而本项目严格协议下仅为 56.03%/76.57%；FBCNet 也由论文表的 75.5%/79.1% 下降为 69.30%/76.81%。因此绝对数值差异并非只由 SE-MHAF 结构造成，还涉及预处理、伪迹保留、测试集归一化、每轮测试选择、多次运行取优等未完整披露的协议差异。

本项目不使用测试标签调参，最终结论限定为：**在当前公开、可复现且无测试泄漏的统一协议下，最终 SE-MHAF-Conformer 已同时超过本项目两条基线。** 不能把论文中的 84.3%/90.3% 直接声称为本实现结果。

## 8. 有效性边界

- 当前比较为每模型一个固定随机种子，不等于多种子统计显著性证明；
- 5% 安全阈值是为约 50–80 个验证试次设置的保守工程规则；
- 最终模型依赖已经只使用训练会话训练完成的 FBCNet 主干，2b 还依赖 V2 时间专家；
- 论文报告数值无法在缺少作者原始代码、随机种子和完整选择协议时被严格复刻。
