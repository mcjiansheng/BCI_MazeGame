# SE-MHAF-Conformer V2 优化说明

> 后续最终版已在 BCIC2a/BCIC2b 达到 70.55%/80.81%，并同时超过原始基线；请以 `SE-MHAF-Conformer_最终优化与验证报告.md` 为最终结论。本文保留 V1→V2 的中间优化证据。

更新日期：2026-07-22

## 1. 优化目标

V1 在 BCIC2a/2b 上分别取得 53.93% 和 75.69%，没有稳定超过 FBCNet。分析表明，V1 只借用了“多尺度”思想，没有保留 FBCNet 的显式九频带和分段对数方差；同时存在参数量过大、头融合初始化非恒等、注意力概率直接叠加到下一层 logits、缺少位置编码、全局均值池化等问题。

V2 不覆盖 V1，而以 `se_mhaf_conformer_v2` 独立注册，保证可以做严格对照。

## 2. V2 总体结构

```text
九频带输入 (B,9,C,1000)
├─ FBC 主路径
│  └─ 分组空间卷积 → 4 段 log-variance → FBC logits
└─ SE-MHAF 残差路径
   └─ 频带均值重构宽带
      → 15/31/63 多尺度卷积
      → 深度空间卷积 → SE
      → 位置编码 → 3 层 Stable-MHAF
      → 注意力池化 → MHAF logits

最终输出 = FBC logits + tanh(β) × MHAF logits
```

`β` 按类别设置并从 0 初始化，因此模型初始输出严格等于 FBC 分支，不会在训练开始时被随机 MHAF 特征拖累。

## 3. 关键修改

### 3.1 真正保留 FBCNet 归纳偏置

V2 直接接收和 FBCNet 相同的 9 个 4 Hz 子带，FBC 主路径保留每频带 32 个空间滤波器、4 个一秒时间段和 `log(clamp(var))` 聚合。SE-MHAF 不再负责从少量样本中重新发现全部频带结构。

### 3.2 残差融合与辅助损失

早期加权平均版本在 A01/B01 上分别只有 65.84%/67.54%，原因是两条支路可共同漂移，使 FBC 主路径不再保持基线能力。最终版本改为零初始化残差：

```text
z = z_fbc + tanh(β) · z_mhaf
L = CE(z,y) + 0.25 CE(z_fbc,y) + 0.25 CE(z_mhaf,y)
```

这样 FBC 路径始终获得直接监督，MHAF 即使在 `β=0` 时也能通过辅助损失学习。

### 3.3 稳定的 MHAF

V1 使用 `softmax(I)`，初始状态就会混合所有注意力头。V2 改为残差头融合 `H_out = H + tanh(γ)·softmax(M)H`，其中 `γ=0`，初始严格为恒等映射。

上一层注意力先执行 `log`、中心化和标准化，再由零初始化的 `tanh(α)` 控制贡献；传递时 detach，避免形成不稳定的跨层梯度链。

### 3.4 轻量化和时序保留

| 配置 | V1 | V2 |
|---|---:|---:|
| Embed dimension | 120 | 48 |
| Transformer depth | 6 | 3 |
| Heads | 10 | 6 |
| FFN expansion | 4 | 2 |
| Branch filters | 16 | 8 |
| Token pooling | 无位置编码 + mean | 可学习位置编码 + attention pooling |

## 4. 正式结果

| 数据集 | V1 Accuracy | V2 Accuracy | 提升 | FBCNet | EEG-Conformer |

## 5. 规模和开销

| 数据集 | V1 参数量 | V2 参数量 | 参数减少 | V2 检查点 | V2 峰值显存 |
|---|---:|---:|---:|---:|---:|
| BCIC2a | 1,076,089 | 78,142 | 92.74% | 0.327 MB | 约 137.3 MB |
| BCIC2b | 1,074,135 | 69,352 | 93.54% | 0.294 MB | 约 89.6 MB |

V2 纯 GPU 单试次前向为 4.47 ms（2a）/3.75 ms（2b）；因为使用九频带，计入当前 CPU 滤波后约为 9.20 ms/9.16 ms。V2 显著降低模型大小和显存，但双路径、辅助损失和 batch 16 使训练总时间高于 V1。

## 6. 使用方法

```powershell
.\.venv\Scripts\python.exe scripts\benchmark_models.py `
  --dataset bcic2a `
  --models se_mhaf_conformer_v2 `
  --subjects all `
  --output outputs\bcic2a_se_mhaf_v2.json
```

将 `--dataset` 改为 `bcic2b` 即可运行 2b。实现位于 `src/bci_maze/models/se_mhaf_conformer_v2.py`。

4. 将 V2 蒸馏到单路径学生模型，降低双路径推理时间；
5. 在线部署使用保留状态的流式 SOS 滤波器组。
